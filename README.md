🚀 Rocketlog

Rocketlog é uma Web Service desenvolvida por João Vitor, com o objetivo de oferecer uma solução para cadastro, gerenciamento e controle de entregas (deliveries).

O projeto permite administrar entregas de maneira organizada, possibilitando o acompanhamento de seus registros e histórico de movimentações por meio de logs.

🎯 Objetivo do projeto

Desenvolver uma API RESTful capaz de facilitar o gerenciamento de deliveries, oferecendo recursos para controlar o ciclo de vida de cada entrega e manter um histórico de suas atualizações.

⚙️ Funcionalidades

Cadastro de deliveries: registro de novas entregas no sistema.

Alteração de deliveries: atualização das informações de entregas cadastradas.

Controle de logs: registro e acompanhamento do histórico de movimentações de cada delivery.

Gerenciamento de entregas: organização e controle das informações relacionadas às entregas.

🛠️ Tecnologias utilizadas

-- Node.js

-- TypeScript

-- Express

-- PostgreSQL

--  Prisma ORM

-- Zod
